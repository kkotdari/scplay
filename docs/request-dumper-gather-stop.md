# 덤퍼 저장소에 부탁하는 것 — 움직이던 몸이 멈추는 순간·다시 나서는 순간의 키

요청: "일꾼 되짚음 제거하고 api에 전달할 내용 정리해줘". 재생기(scplay)는 참값 키 사이를 **곧게 잇기만** 한다 —
자취를 걸음표로 다시 짐작하는 길은 넣었다가 걷었다(참값을 렌더러가 다시 주무르는 이중 모형이라서). 남은 것은
덤퍼가 **멈춘 순간**을 키로 적는 일 하나다. 이 문서는 그 저장소(`stargayte-api` 의 `openbw/bwdump.cpp`)에 넘길 부탁이다.

## 무엇이 문제인가

`bwdump.cpp` 의 키 솎기(`anchor9`/`pend9` 블록)는 표본을 **다음 셋일 때만** 키로 적는다:

1. 상태·종류·임자가 바뀔 때(`anc.state != cur.state …`)
2. 닻(anchor)에서 지금 자리로 그은 **곧은 선**에서 직전 표본이 `DEV9`(4px) 넘게 벗어날 때
3. 방향이 `HEAD9`(28/256) 넘게 돌 때 · 움직이는 상태(1·5·7·8)로 240프레임이 지났을 때

그런데 **곧게 걸어가서 그 자리에 멈춰 서는 것**은 셋 어느 자에도 안 걸린다 — 멈춘 뒤의 표본은 다 같은 점이고 그 점은
닻 → 지금 자리 선의 끝이라 벗어남이 0 이다. 채집 상태(5 · `u_gathering`)는 원작의 gathering 깃발이라 **미네랄로
걸어가는 동안 · 밭 앞에 줄 선 동안 · 캐는 동안**이 한 상태다. 곧 한 번 캐러 가는 길의 키는 이 둘뿐이다:

```
출발(상태 5 · 본진 앞)  ───── 곧은 선 ─────  캐서 든 순간(상태 7 · 미네랄 앞)
```

재생기가 그 사이를 곧게 이으면 **걸음 1~2초 + 줄 서기 + 캐기 3초**를 한 속도로 나눠 가진다 — 일꾼이 제 걸음의 1/3
로 슬금슬금 다가가 캐기가 끝나는 순간에야 미네랄에 닿는다. 되돌아오는 길(7·8)은 멈추는 몫이 없어 멀쩡하다.

같은 꼴이 채집 말고도 있다: 이동 명령(상태 1)으로 걸어가 **도착해 서 있는** 유닛 — 도착 뒤 다음 명령까지 상태가 안
바뀌면(멈춰 서서 `u_movement_flag(u, 2)` 가 내려가 상태 0 이 되면 1번 규칙에 걸리므로 대개는 괜찮다) 같은 병이다.
채집은 깃발이 멈춤과 무관하게 서 있어 늘 걸린다.

## 무엇을 적어 달라는가 — 키 둘

움직이는 상태(1·5·7·8)의 몸에 대해:

| 키 | 언제 | 어느 표본을 |
| --- | --- | --- |
| **멈춤** | 자리가 `STOP9`(제안 6 프레임 ≒ 0.25초) 동안 한 픽셀도 안 변했을 때 | **처음 멈춘 프레임**의 표본 |
| **나섬** | 멈춤 키를 적은 뒤 자리가 다시 변하기 시작할 때 | **마지막으로 멈춰 있던 프레임**의 표본 |

그러면 채집 토막이 `출발 → 멈춤(밭 앞) → 나섬 → …` 으로 갈려 재생기는 아무것도 안 해도 제 걸음으로 걷고 밭 앞에서
선다. 재생기의 '서 있음' 판정(`posAt` 의 초당 0.4타일 문턱)은 멈춤~나섬 토막을 저절로 '안 움직임'으로 읽는다.

· **형식은 한 톨도 안 바뀐다** — 키 구조체(`key_t`)·이진 판·글자 갈래 그대로이고 키가 몇 줄 더 실릴 뿐이다.
  재생기 쪽에 고칠 것이 없고, 옛 뭉치는 종전대로 읽힌다(그 뭉치에서는 여전히 슬금슬금 다가간다).
· `STOP9` 는 `BWDUMP_DEV`·`BWDUMP_HEAD` 처럼 환경변수(`BWDUMP_STOP`)로 열어 두면 값을 실측으로 고를 수 있다.
  0 이면 종전과 같다(끔).
· **밀림 떨림은 안 걸린다** — 밭 앞에 줄 선 일꾼은 서로 밀려 좌표가 잔잔히 흔들리므로 '한 픽셀도 안 변함'이 계속
  이어지지 않는다. 그러면 멈춤 키가 안 나고 종전과 같다(그 자리는 대개 미네랄 바로 앞이라 눈에 안 띈다). 더 잡으려면
  '`STOP9` 동안 닻에서 `DEV9` 안'으로 넓힐 수 있지만, 먼저 한 픽셀 규칙으로 실측하는 것을 권한다.

## 어디에 넣는가 — 훅 자리

키 솎기 블록의 `if (pit != pend9.end()) { … }` 안, 세 규칙 검사(`dev > DEV9 || hd > HEAD9 || …`) **앞**이다. 이미
`pv`(직전 표본)·`cur`(지금 표본)·`anc`(닻)·`moving9` 가 손에 있으니 필요한 것은 태그마다 **멈춰 있은 프레임 수** 하나다.

```cpp
    // 태그마다: 자리가 안 변한 채 이어진 프레임 수 · 그 첫 표본(멈춤 키 후보)
    std::map<unsigned, std::pair<int, key_t>> still9;
    const int STOP9 = getenv("BWDUMP_STOP") ? atoi(getenv("BWDUMP_STOP")) : 6;
    …
        if (pit != pend9.end()) {
          const key_t pv = pit->second;
          const bool moving9 = cur.state == 1 || cur.state == 5 || cur.state == 7 || cur.state == 8;
          if (STOP9 > 0 && moving9) {
            auto sit = still9.find(tg);
            if (cur.x == pv.x && cur.y == pv.y) {
              if (sit == still9.end()) sit = still9.emplace(tg, std::make_pair(0, pv)).first;
              sit->second.first++;
              if (sit->second.first == STOP9 && !(anc.x == pv.x && anc.y == pv.y)) {
                /* 멈춤 — 처음 멈춘 표본을 키로. 닻이 이미 그 점이면(막 나서서 아직 그 자리) 적을 것이 없다. */
                why9[6]++; emit9(tg, sit->second.second); anchor9[tg] = sit->second.second;
              }
            } else if (sit != still9.end()) {
              if (sit->second.first >= STOP9) {
                /* 나섬 — 마지막으로 멈춰 있던 표본(pv)을 키로. 그 뒤 곧은 선의 닻이 곧 이 점이다. */
                why9[7]++; emit9(tg, pv); anchor9[tg] = pv;
              }
              still9.erase(sit);
            }
          } else still9.erase(tg);
          … (종전의 dev · hd · 240프레임 검사 그대로)
```

· `why9` 를 여덟 칸으로 늘리면 `--tracks` 끝의 통계 줄에 멈춤·나섬 수가 함께 찍힌다(값 어림의 자).
· 상태가 바뀌는 순간(1번 규칙)은 `still9` 를 비운다 — 안 비우면 채집(5) → 든 순간(7) 뒤에 옛 멈춤 셈이 남는다.
  사라짐(상태 3) 갈래에서도 `still9.erase`.
· `u->position` 대신 `u->current_speed`(fp8 · openbw `unit_t`)로 재도 된다 — 다만 그 값은 원작의 가속 모형이 내는
  값이라 '멈춤'의 문턱을 따로 정해야 하고, 자리 비교는 이미 손에 든 값이라 새 필드를 안 읽는다.

## 값 어림

일꾼 하나가 한 번 캐러 가는 길(≒ 8초)에 키가 **둘 는다**(밭 앞 멈춤 · 나섬). 8인 20분 경기 · 일꾼 60명 · 캐기 150번이면
**약 1만 8천 줄** — 지금 자취 키(수십만)의 몇 퍼센트다. 240프레임 규칙이 같은 구간에 내던 키(캐는 3초 동안 하나)는
멈춤 키가 닻을 옮기므로 대개 도로 사라진다.

## 검산

```
BWDUMP_STOP=6  <bwdump …> --tracks <x.rep>          # 통계 줄의 멈춤·나섬 수가 0 이 아니어야 한다
BWDUMP_STOP=0  …                                      # 종전과 줄 수가 같아야 한다(끔)
node scripts/openbw-tracks-check.mjs <구운 뭉치>       # scplay 자물쇠 — 판 번호·절 길이 그대로 통과
OPENBW_BWDUMP=… OPENBW_DATA=… node scripts/openbw-tracks-check.mjs --rep <x.rep>   # 글자 ↔ 이진 줄마다 맞댄다
```

눈으로는 재생기에서 본진 미네랄 밭을 8배로 당겨 놓고 본다 — 일꾼이 **제 걸음으로** 미네랄에 닿아 서고, 캐는 동안
걷기 컷이 안 돌아야 한다(지금은 캐기가 끝나는 순간에야 닿는다).
