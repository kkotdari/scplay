## 건설 명령의 고스트(반투명 초록 네모)는 자료가 없다 — 덤퍼가 건설 명령을 안 적는다

  안 실린다. 리플레이가 아는 것은 **클릭한 결과**(Build 명령 = 건물 종류 + 타일 자리)뿐이다.
